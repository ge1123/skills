# 固定畫板：TSX＋SVG

用於固定尺寸的第一版構圖、介面畫面、海報、資訊圖與簡報單頁等靜態視覺稿。目標是快速得到可預測的位置與比例，而非模擬瀏覽器的內容流動。

## 原稿與構圖

- 使用 TSX 組織畫板與必要的共用元件；保留 SVG 的文字、圖形與路徑作為可編輯來源。若已有更簡單的直接 SVG 工作流程，可沿用，無需為單張稿建立完整應用程式。
- 依用途設定明確的畫板尺寸與 `viewBox`。多畫板可共享設計參數，但每張保有自己的名稱與尺寸。
- 以數值、資料陣列與小型輔助函式產生重複的列、刻度和圖形，避免手工複製大量座標。保留有意義的命名，不用壓縮成難讀的路徑換取較少字元。
- 正文與標題保留為文字。規劃長文字的換行、行距及最大可用寬度；內容變動會頻繁影響其他元素時，改用流動排版，而不是反覆堆疊座標修補。
- 圖形不應為裝飾而淹沒內容。圖表的數值、標籤、單位與漲跌語意要一致；示意圖形與資料使用清楚的示意標示。

## 預覽與輸出

- 用適合現有環境的最小流程將 TSX 渲染成 SVG；需要預覽容器時，可用簡單 HTML 承載。HTML 容器不代表成品用途是網站。
- 多張 SVG 放在同一文件時，為漸層、裁切、遮罩與可存取標籤等識別碼加上畫板前綴，避免彼此覆蓋。
- 使用實際可用且能顯示目標語言的字型。檢查真正的渲染結果，特別留意文字邊界、基線、圖層遮擋及畫板外的內容。
- 預覽可等比例縮放，但不能把整張縮小後的畫面當成手機排版驗證。若任務需要重新換行與排列，使用 [流動排版](flow-layout.md)。
- 提供 TSX／SVG 原稿及預覽；依要求再輸出 PNG、PDF 或其他格式。對需要特定成品規格的任務，以該格式的要求決定匯出與驗證流程。
