# 流動排版：TSX＋HTML＋CSS，按需加入 SVG

用於需要檢查真實文字、表單、表格、可變內容或多尺寸重排的靜態稿。它也可作為非網頁成品的排版預覽，但交付格式仍以使用者要求為準。

## 元件分工

- 用 TSX 組織必要的共用結構與內容資料；輸出可選取文字的 HTML。表格、標題、清單、表單使用符合用途的原生元素。
- 用 CSS 管理字型、色彩、間距與 Grid／Flex 排版。建立少量共用參數，保持元件一致，不為單次草稿建立過度完整的設計系統。
- 圖示、走勢、示意圖與特殊圖形可使用 SVG。需要精確構圖的局部可混合使用 SVG，但主要內容仍依需求交由 HTML 排版。
- 不用整頁 SVG、PNG 或截圖替代本應驗證的文字與內容結構。圖片可以是合理的視覺素材，截圖可以是預覽；兩者都不取代約定的可編輯原稿。

## 靜態範圍與呈現

- 靜態稿不必安裝客戶端框架或加入 JavaScript。可用現有的 TSX 靜態匯出流程，或直接編寫 HTML／CSS；依已存在的環境選擇最少必要依賴。
- 只有展示需求涉及的頁面導覽才加入連結。尚未實作的操作以清楚的靜態狀態呈現，不讓展示表單傳送或儲存真實帳密，也不假裝已完成身分驗證。
- 當內容可能變長時，測試代表性的長標題、數字或表格。需要手機版才設定有用的斷點；資料表可在自身容器內捲動，不應迫使整個頁面橫向溢出。
- 縮小整頁或截圖不算響應式設計。驗證各目標尺寸下的實際換行、元件順序、字級與內容可讀性。

## 檢查與交付

- 在目標尺寸開啟實際 HTML，等待字型與資源載入後檢視；檢查頁面高度、橫向溢出、圖表標籤及表格對齊。若有必要導覽，確認連結能到達對應畫面。
- 將多個頁面放入白板時，用隔離的 HTML 畫板或截圖預覽避免 CSS 互相影響；保留可直接開啟的原頁。選擇載體依環境而定，不為白板而把產品頁轉成圖片。
- 提供 TSX、HTML／CSS 與可直接開啟的預覽，必要時附最少執行指令。若需要離線使用，確認相關資源一併交付且沒有未說明的遠端依賴。
- 只驗證本次設計及展示行為，不替未被要求的產品功能建立後端或測試體系。
