# Skills

可重複使用的個人設計與工作流程技能。

| Skill | 用途 |
| --- | --- |
| [design-draft](design-draft/SKILL.md) | 將需求製作成可編輯的靜態設計稿，涵蓋介面、海報、資訊圖與簡報單頁構圖。 |

## design-draft

固定尺寸構圖預設使用 TSX＋SVG；需要長文字、表格、內容流動或響應式驗證時，使用 TSX＋HTML＋CSS，按需加入 SVG。只載入本次任務需要的指引，不強制每次使用四種技術。

將 `design-draft` 資料夾安裝到技能目錄後，可使用 `$design-draft` 呼叫，例如：

- `使用 $design-draft，製作三張手機 App 的靜態設計稿，風格簡潔，先確認主要內容。`
- `使用 $design-draft，將活動資訊製作成 A3 海報設計稿。`
- `使用 $design-draft，設計有長表格的後台頁面，同時檢查桌面與手機排版。`

技能內容、參考與介面設定都放在 `design-draft/`，可獨立安裝。設計稿的原始檔、預覽與版本比較依每次任務產生，不包含在技能套件內。
